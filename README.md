### [CS Radio Library](https://github.com/mjyt13/agents-library-frontend)

Веб-приложение для прослушивания голосовых реплик различных фракций CS2/CS:GO и поиска агентов с такими репликами. Все материалы на фронте, никакого подключения сервисов не требуется.

📄 [Подробнее — README проекта](https://github.com/mjyt13/agents-library-frontend#readme)

### [Брадобрей Пати](https://github.com/mjyt13/bradobrei-party)

Учебный проект корпоративной информационной системы для сети барбершопов: бэкенд на Go (Gin, GORM, PostgreSQL, JWT-авторизация) и фронтенд на React + TypeScript, разворачивается через docker-compose. В репозитории также лежит проектная документация — ТЗ, C4-диаграммы архитектуры, use-case и ER-модели БД.
