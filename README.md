# Привет, я Максим 👋

## О себе

Frontend-разработчик с опытом около года — работал и в компании, и на отдельных заказах. Специализируюсь на клиентской части больших систем: слежу за надёжностью и скоростью приложения, продумываю пользовательский путь так, чтобы сократить время знакомства с продуктом.

Сейчас углубляюсь в backend (в частности на JS) и DevOps. Живу в Перми, открыт к удалённой работе.

## Мои проекты

### [Vogue Station](https://github.com/mjyt13/vogue-station-frontend)

Pet-проект: 3D-редактор одежды на three.js (замена модели, цвета, паттерна с live-превью и разверткой UV) поверх настоящего API — NestJS, Prisma/PostgreSQL, S3-хранилище. Есть аккаунты, личный кабинет с сохранёнными образами, публикация в галерею через модерацию в админке. Фронтенд и бэкенд — два отдельных репозитория, как в реальном продукте.

📄 [Подробнее — README проекта](https://github.com/mjyt13/vogue-station-frontend#readme) · [бэкенд](https://github.com/mjyt13/vogue-station-backend)

### [CS Radio Library](https://github.com/mjyt13/agents-library-frontend)

Веб-приложение для прослушивания голосовых реплик различных фракций CS2/CS:GO и поиска агентов с такими репликами. Все материалы на фронте, никакого подключения сервисов не требуется.

📄 [Подробнее — README проекта](https://github.com/mjyt13/agents-library-frontend#readme)

### [Брадобрей Пати](https://github.com/mjyt13/bradobrei-party)

Учебный проект корпоративной информационной системы для сети барбершопов: бэкенд на Go (Gin, GORM, PostgreSQL, JWT-авторизация) и фронтенд на React + TypeScript, разворачивается через docker-compose. В репозитории также лежит проектная документация — ТЗ, C4-диаграммы архитектуры, use-case и ER-модели БД.

📄 Подробнее — README: [бэкенд](https://github.com/mjyt13/bradobrei-party/tree/main/bradobrei_party/backend#readme) · [фронтенд](https://github.com/mjyt13/bradobrei-party/tree/main/bradobrei_party/frontend#readme)
